# 🧠 Genical Website

A modern and responsive mental health website built using HTML, CSS, and JavaScript.

## 📌 About The Project

Genical is a responsive website designed with a clean and modern user interface.
The project focuses on creating a simple and user-friendly experience.

## 🚀 Features

- Responsive design
- Modern user interface
- Navigation bar
- Hero section
- Services section
- About section
- Contact section
- CSS animations
- Mobile-friendly layout

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
